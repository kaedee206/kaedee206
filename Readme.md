### 🚀 Featured Project: KaedeeMC

**System Optimization & Resource Management**

KaedeeMC is a custom Minecraft server project focused on extreme performance tuning and resource optimization. 

- **The Challenge**: The server experienced CPU overload, memory leaks (out of RAM), and low TPS (Ticks Per Second dropping below 15), causing a poor player experience.
- **My Solution**: 
  - Developed custom Java plugins to manage resources efficiently: `smart chunkloader`, `chunkholder`, `mod spawn manager`, and `limit mobs spawn`.
  - Tuned configuration files extensively to balance entity processing and hardware constraints.
- **The Results**:
  - ⚡ **Startup Time**: Reduced from **100 seconds down to 40 seconds**.
  - 📉 **CPU Usage**: Stable at **< 30%** even with 10 concurrent players exploring the map.
  - 🧠 **RAM Optimization**: Prevented memory leaks entirely. The server now runs smoothly utilizing only **6GB out of 12GB RAM**.
  - 🎮 **Performance**: Solved low TPS and significantly improved ping stability.
